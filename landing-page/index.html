Features

🏷️

Categorized Comments

Organize annotations with five built-in categories: Critical, Major, Minor, Suggestion, and Question. Each category has distinct colors and icons for instant visual recognition.

✏️

Text Highlighting

Select any text in your PDF and create highlighted annotations. All highlights are stored with precise coordinates and synchronized across the document.

📤

Export Options

Export all annotations to JSON or Markdown format. Perfect for sharing reviews, generating reports, or archiving feedback.

🔍

Search & Filter

Quickly find annotations by category, content, or page number. Advanced filtering helps you focus on specific types of feedback.

🌓

Dark/Light Mode

Comfortable reading experience with automatic theme switching. Dark mode by default, with seamless light mode support.

💾

Local Storage

All data stored locally in SQLite database. Your documents and annotations never leave your computer. Zero cloud dependencies.

Download

🪟

Windows

Windows 10 and later (64-bit)

Download .exe

Installation Notes:

  • Run the downloaded installer
  • You may see "Windows protected your PC" warning
  • Click "More info" → "Run anyway"
  • Auto-update is fully supported
🍎

macOS

macOS 10.15 (Catalina) and later

Download .dmg

Installation Notes:

  • Open DMG and drag app to Applications
  • First launch: Right-click → Open
  • Or run: xattr -cr "/Applications/Reviewer 2.app"
  • Auto-update requires manual download (no Apple notarization)
🐧

Linux

Ubuntu, Debian, Fedora, and others

Download .AppImage

Installation Notes:

  • Make executable: chmod +x Reviewer*.AppImage
  • Run: ./Reviewer*.AppImage
  • Or use .deb package for Debian/Ubuntu
  • Auto-update support varies by distribution
